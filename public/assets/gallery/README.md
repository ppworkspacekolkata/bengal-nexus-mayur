# Bengal Nexus Exports - Gallery Folder

## English Instructions:
Simply place your gallery images in this folder. The website will automatically detect and load them.
1. Name your images as numbers: `1`, `2`, `3`, `4`, `5`, `6`, etc.
2. Supported file extensions: `.jpg`, `.png`, `.webp`, `.jpeg`
3. Example filenames: `1.jpg`, `2.png`, `3.webp`, `4.jpeg`
